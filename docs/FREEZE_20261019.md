# Demo 冻结记录（2026-10-19）

## 冻结内容

2026-10-19 的冻结包含 581 项源文件摘要、50 项原生与几何依赖指纹。源码由 main 分支管理，提交记录保存在 Git 历史中。

实验入口为 run.sh → scripts/run_acceptance.py。脚本在仓库外 Demo_runs 建立隔离工作副本，保存编辑器状态，加载 IndustrialArea（复件），启动 PIE 并等待 24 辆车就绪，然后执行真实 UE 验收、位姿审计和道路包络审计。收尾阶段结束 PIE 并恢复关卡、相机、自动保存及节流设置。

视口相机沿用操作者当前位姿，结束时恢复运行前保存的相机信息。默认运行直接进入 UE 验收；轻量预检、回归和原生门禁作为独立验证流程。

## 操作约定

每次运行保持单个 UE 编辑器，验收独占 AirSim RPC 端口及实验输出目录。结果入口为 acceptance_summary.json，详细执行过程写入 execution.log。

Demo 的运行配置、实验结果及源码摘要见 [冻结说明](FREEZE_20261020.md)，实验数据下载入口见 [README](../README.md)。
