# 通行状态转换的共同校验

当前实现已迁入 Demo，默认绑定原 UE 工程 `/home/aipc/Traffic_ue4/Traffic_ue4.uproject`，运行产物在仓库外 `../Demo_runs/`。迁移前开发与十轮测试位于 Traffic_Arrangement，使用独立 agent 工程；这些是历史验证背景。完整调用关系及已知缺口见 [当前运行说明](CURRENT_RUNTIME.md)。

## 约束与入口

`maneuver_contract.py` 定义入口前停车线、尾部清空距离、连通动作出口及完整车身扫掠采样。停车线和尾部清空是不同概念，分别保留 7.8m 与 6m，不能相互替换。撤销可行性使用反应、减速及控制步进距离，不重复加入跟车指导模型默认的0.5m余量，避免把合法停车线前的已停稳车辆错误锁定。

`traffic_transition.py` 中的 `TrafficTransition` 描述候选变更，`TransitionValidator` 对同一观测帧检查：

- 撤销授权后能否遵守重新生效的停车线；权限区分已授权、无法在线外停车、已进入、已清空以及路线版本失配。
- 改道是否保留已行驶与制动所需前缀，是否引入已越过的停车线，以及连通动作的完整出口扫掠是否会困住其他车辆。被扫掠覆盖的车辆须有在申请车保持实测位置时可执行的前进清空路径；同时考虑实测车身和当前帧制动预测。
- 新授权是否与其他车实测车身或制动路径冲突。时间窗兼容不能覆盖实测车身检查。
- 新让行是否要求无法执行的立即停车，清空义务是否在现有许可、停车边界、检查点和车身障碍下可达。
- 新增等待依赖是否闭合等待环；仅去除本次已重新检查的同一个请求的旧拒绝证据，保留物理跟车等其他依赖。
- 任务段交接须保持实测停车位置、朝向和必要共享道路权利，并在更换执行路线的同一事务内退出旧路线权限。实车占用始终保留。

`LocalTraffic.commit_transition()` 是共同提交入口。校验拒绝不会更改路线、权限或让行关系；提交前比较观测/执行状态戳，提交异常时回滚内存状态。修改、授权及任务段交接不在校验和提交之间调用 RPC。日志记录 `TRANSITION_REJECTED`、`TRANSITION_COMMITTED` 及递增 revision。

已接入的业务入口：停驶/行驶改道、任务段交接、通行权申请及其中的竞争撤销/让行、超时回收、等待环恢复撤销、前进清空让行授权。竞争撤销的提前可行性检查复用同一校验器；最终组合变更仍完整校验后提交。

调度侧改道和任务交接传入完整的当前观测帧及对应车身，避免将申请车的新状态与其他车辆的上一帧状态混用。校验器投影当前观测以核对制动与停车边界，不修改执行进度。

## 验证方式

```bash
PYTHONDONTWRITEBYTECODE=1 PYTEST_DISABLE_PLUGIN_AUTOLOAD=1 PYTHONPATH=src:scripts \
  python3 -B -m pytest -q -p no:cacheprovider -p no:nose tests
PYTHONDONTWRITEBYTECODE=1 python3 -B scripts/replay_traffic_transitions.py
./run.sh --output /absolute/external/output
```

`-p no:nose` 避免本机旧版 pytest 将测试辅助函数 `setup(positions)` 当成无参数 nose 钩子调用；不改变产品代码或测试断言。

历史失败重放使用保留日志中的路线、位置、权限事件及原生车身，不启动 UE，不移动任何车辆。第 4 轮使用事件前后相邻诊断帧，车身来源和约 0.000410m 的后车位姿差异已在 fixture 中注明；第 7 轮保留了与撤销事件同时间的轨迹帧。重放证明相应转换被阻止，不等同于证明整轮物理执行成功。

边界测试覆盖不同撤销入口、低速/零速、停车线附近、8秒时刻前后、前进/倒车类动作、等待图、组合拒绝及提交回滚、观测帧变化、任务段交接和移动后车。已有等待图穷举也通过同一个等待环实现。

迁移前独立冷启动实验由仓库外编排器每轮恢复同一工程文件基线，新开一个编辑器进程，再通过当时的 Traffic_Arrangement/run.sh 运行 1 倍速验收，退出后再开始下一轮。当前 Demo 的 run.sh 本身不恢复文件基线，也不新开或关闭编辑器。工作副本将依赖路径绑定到实际受测工程，保留并核对原有预期摘要，同时检查编辑器工程路径和实际已加载原生库，避免审计了另一个工程。

## 范围

这是有观测时效、制动模型、地图与局部预测范围前提的安全和局部解阻检查，不是所有车队状态的全局活性证明。动态障碍变化、建模误差与真实物理时序仍需真实 UE 验证。当前 frozen_files.json 记录新版实际源码摘要，旧摘要由 Git 历史保留；刷新摘要不表示物理验收通过。十轮中出现一次等待环停滞，说明后续动态执行仍可能失去解阻路径，不能据共同校验宣称全局活性成立。
