# 通行状态转换校验

Demo 的改道、授权、撤销、让行及任务段交接共用 TrafficTransition 与 TransitionValidator。默认 UE 工程为 `/home/aipc/Traffic_ue4/Traffic_ue4.uproject`，结果写入仓库外 Demo_runs。模块调用关系见 [运行流程](CURRENT_RUNTIME.md)。

## 几何与停车约束

maneuver_contract.py 定义入口前停车线、尾部清空距离、动作出口和完整车身扫掠采样。停车线偏移为 7.8m，尾部清空距离为 6m，分别用于入场停车和权限释放。

撤销可行性采用反应距离、减速距离及控制步进距离；跟车模型的 0.5m 接近余量用于跟车速度指导。校验器将实测位置投影到当前路线，使用局部投影结果核对停车边界，执行进度由控制器推进。

## 共同校验

| 变更 | 校验内容 |
|---|---|
| 权限撤销 | 按已授权、已承诺、已进入、已清空和路线失配区分许可阶段；允许安全停车的权限进入撤销流程 |
| 改道 | 保留行驶和制动前缀、实测位姿与必要动作；对近端新增动作核对停车边界和出口扫掠 |
| 通行授权 | 核对路线版本、实测车身、制动路径及相容关系 |
| 让行与清空 | 核对停车位置、清空终点和当前约束下的可达路径 |
| 等待依赖 | 检查新增依赖与当前关系形成的等待环 |
| 任务段交接 | 保持实测停车位姿、朝向和必要道路权利，在同一事务中退出已清空的路线权限 |

动作扫掠覆盖其他车辆时，改道校验要求其具有前进清空路径，并将当前车身、制动预测、现有权限和停车边界纳入检查。物理占用持续保留到实测清空。

## 提交

LocalTraffic.commit_transition() 统一执行“读取观测帧 → 校验候选变更 → 比较状态戳 → 发布 → 记录 revision”。校验拒绝保留提交前状态，发布异常回滚。校验与发布在同一同步调用链完成。

事件包括 TRANSITION_REJECTED 和 TRANSITION_COMMITTED。竞争撤销的提前检查和最终组合变更复用同一个校验器。接入入口包括停驶及行驶改道、任务交接、通行申请、竞争撤销和让行、超时回收、等待环恢复撤销以及前进清空授权。

调度改道和任务交接传入完整当前观测帧及对应车身，使申请车与受影响车辆使用同一帧数据。

## 验证

```bash
PYTHONDONTWRITEBYTECODE=1 PYTEST_DISABLE_PLUGIN_AUTOLOAD=1 PYTHONPATH=src:scripts \
  python3 -B -m pytest -q -p no:cacheprovider -p no:nose tests
PYTHONDONTWRITEBYTECODE=1 python3 -B scripts/replay_traffic_transitions.py
./run.sh --output /absolute/external/output
```

pytest 的 no:nose 参数使 setup(positions) 按辅助函数使用。记录场景重放在离线环境中检查路线、位置、权限事件和原生车身。夹具记录了相邻诊断帧的约 0.000410m 位姿差异及精确事件时间，便于按证据复核转换决定。

回归覆盖停车线、低速、超时边界、前进和倒车动作、等待图、组合变更、回滚和任务段交接。942 项测试及 4 个重放场景通过，十轮冷启动结果为 9 PASS、1 FAIL，详见 [验证记录](VALIDATION_20261020.md)。

## 动态执行

共同校验的依据是当前观测与有限预测。后续车辆运动由逐帧轨迹保护继续调节，持续解阻需要随物理状态变化重新评估。现有等待环恢复优先撤销可安全停车的权限；撤销受限时的路线与多车协调策略是当前完善重点。
